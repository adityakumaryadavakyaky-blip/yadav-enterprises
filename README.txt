YADAV ENTERPRISES WEBSITE

Files:
- index.html : complete responsive website
- assets/shop-poster.png : your supplied shop poster

Publish with GitHub Pages (Android):
1. Extract this ZIP.
2. Open your GitHub repository (for example, aditya-chess or a new repository for this business).
3. Upload index.html and the assets folder (including shop-poster.png) to the repository root.
4. In Settings > Pages, select Deploy from a branch, choose main and / (root), then Save.
5. Wait for GitHub Pages to publish, then open the Pages URL.

Online interactions:
- Call button opens the phone dialer.
- WhatsApp buttons open a chat with 9005586366.
- Enquiry form creates a pre-filled WhatsApp message; the customer reviews and sends it.
- No online payment, live inventory, or automatic order database is included.
